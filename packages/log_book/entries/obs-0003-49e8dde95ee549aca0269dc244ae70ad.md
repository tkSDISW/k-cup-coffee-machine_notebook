## Survey: existing coffee-machine system models, and whether any cover pod systems

Quick web survey, not exhaustive. **Finding: no model of a pod or K-Cup system was found.** Every coffee model located describes a bean-to-cup, espresso or vending machine, or is a teaching example. The closest pod-relevant material is a Capella forum answer on modeling capsules (row 1).

**Takeaways**
1. **We are modeling a gap.** No open pod-system model was found, so the K-Duo pod model has no direct precedent to copy or reconcile with.
2. **Pod handling is a modeling decision with guidance:** treat the pod as an **exchange item** (class with attributes such as pod type and coffee mass) in a data package, since the machine is the System of Interest. A separate model with the pod as SOI is optional later. Candidate practice for this project; not yet adopted.
3. **Nothing here replaces the sources chosen in DEC-0003.** These are method and style references, not product evidence.
4. **Limits of this survey:** I could not search paywalled, vendor-internal or non-indexed Capella repositories. If you have seen other models, add the links here.
