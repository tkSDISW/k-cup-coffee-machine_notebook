## Candidate open-source sources for the K-Cup machine model (initial survey)

First web survey of openly available material. Nothing selected yet. Each item is tagged with the ARCADIA phase it would mainly feed.

**Strong candidates (describe a K-Cup brewer's behavior and parts)**
- **Keurig hardware-hacking projects (SmartKeurig, two GitHub repos):** document the control board's interfaces: lid open/close lever, status LEDs, temperature sensor, pressure sensor, user buttons, and pump motor power. Feeds **System Analysis** (system boundary, actors, functional exchanges) and **Logical Architecture**.
  - https://www.github.com/shane1027/SmartKeurig
  - https://github.com/shildenbrand/SmartKeurig
- **Ohio State "Keurig project" (Phase 1 product and process research):** a student teardown of a Keurig B130 with component-level notes (button assembly, K-Cup holder, needles that puncture the pod top and bottom, water tank, material choices) plus K-Cup manufacturing process notes. Feeds **Physical Architecture** and **Operational Analysis** (pod supply chain). https://u.osu.edu/keurigproject/phase-1-understanding-product-and-process/initial-research-manufacturing-of-a-pod-coffee-maker
- **iFixit Keurig K-Duo device page:** published specs (power, reservoir volume, brew temperature range, serving sizes, dimensions) and feature list. Feeds **System Analysis** (non-functional requirements, capabilities) and **Physical Architecture** (quantitative properties). https://www.ifixit.com/Device/Keurig_K-Duo

**Supporting / contextual**
- **Wikipedia, single-serve coffee container:** K-Cup context; the original K-Cup patent has expired, so clone pods exist. Useful for **Operational Analysis** (stakeholders, pod ecosystem). https://en.wikipedia.org/wiki/Single-serve_coffee_container
- **Open Source Espresso Machine for Makers (Univ. of Sheffield MEng thesis):** reverse-engineering method and open documentation for an espresso machine, not a K-Cup machine. Useful as a process reference. https://cdn.hackaday.io/files/1621766938537984/Thesis%20-%20Zack%20Moss%20-%20David%20Polson.pdf
- **Intelligent Pour-Over Coffee Machine (UIUC/ZJU ECE 445 report, open-sourced):** requirements-and-design report format that could inform how we write requirements. Not K-Cup. https://github.com/PhiloCoffee/intelligent-pour-over-coffee-machine
- **johnwebbcole/kcup:** an open 3D-printable K-Cup dispenser. Peripheral; at most relevant to an operational scenario for storing pods. https://github.com/johnwebbcole/kcup

**Gaps noticed**
- No open source found yet that is a full requirements spec or system architecture for a K-Cup brewer. Sources are teardown and hacking oriented, so the **system-level behavior will need modeling assumptions**, to be logged explicitly as assumptions.
- Licenses were not checked. Before copying any text or figures into the model, confirm each source's license.

**Housekeeping**
- Resuming the `K Cup Coffee Maker Model` repo through `capella-fabric` worked with the existing GitHub authorization (no connect link needed), but the repo has **no `.aird` file**: there is no Capella project in it yet. The first model step will be creating one.
