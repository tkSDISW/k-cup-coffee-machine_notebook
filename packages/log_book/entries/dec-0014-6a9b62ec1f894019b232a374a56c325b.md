## Decision: keep Coffee Drinker as the only actor in Operational Analysis

**Decided by the engineer**, answering comment 4 of OBS-0008 (actor flags).

**Decision.** The actor flag stays as it is: **Coffee Drinker** is the only actor (flagged as a human actor); Coffee-Making Equipment, Coffee Supply Chain, Equipment Support, Waste Handling and Utilities Supply remain ordinary entities.

**Rationale (engineer's)**
- In Capella the notation for actors changes in System Analysis, and a property marks an actor as human. Actors currently display as a stick figure.
- Flagging the other entities as actors would give them the same symbol and could confuse readers who are not familiar with ARCADIA, since only the drinker is a person.
- Keeping the stick figure for the human actor alone makes the OCB and later diagrams easier to read for a mixed audience, which matters for an educational model.

**Consequences**
- No model change is needed: the current flags already match this decision.
- The flag in OA does not need to anticipate System Analysis. Which elements become actors there is decided when the system boundary is drawn.
- OBS-0008 comment 4 is resolved.
