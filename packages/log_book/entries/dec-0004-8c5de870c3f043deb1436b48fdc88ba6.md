## Decision: model scope is K-Duo pod-brewing mode only

**Decided by the engineer**, choosing option 1 from DEC-0003.

- **Basis product:** Keurig K-Duo (2019), used for nameplate data, user-facing behavior (user manual) and published specs.
- **In scope:** the K-Cup pod brewing path: user, pod, water reservoir, heating, pumping, lid and pod holder with piercing, brew control and user interface, dispensing into a mug.
- **Out of scope for now:** the drip carafe path, hot plate, programmable auto-brew, pause and pour, and ground-coffee brewing. These can be added later as an extension.
- **B130 teardown role:** structural analogue for the pod brewing path only. **Every B130-derived element used in the K-Duo model is logged as an assumption**, naming the B130 source.
- **Consequence:** where the K-Duo manual describes behavior shared by both modes (for example reservoir, power, brew size selection), keep the pod-relevant part and note what was left out.
