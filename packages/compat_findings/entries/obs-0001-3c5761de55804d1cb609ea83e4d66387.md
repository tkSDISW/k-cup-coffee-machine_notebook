## Compat finding 1: read operations work on an empty Capella 6.1 project (confirmation)

**Result:** worked as expected. No problems found.

1. **Tool and call:**
   - `clone_capella_repo(repo_url="https://github.com/tkSDISW/k-cup-coffee-machine", branch="master", agent_id=<registered agent>)`, no credential (resumed from the stored GitHub authorization).
   - `list_object_types(session_id)`.
   - `browse_model(phase="OA", object_type=...)` for `Entity Package`, `Entity`, `Activity Package`, `Capability Package`, `Data Package`.
2. **Context:** Capella 6.1; model commit `304e8a6` (2026-11-20, 11:38 US Eastern); project file `K Cup Coffee Maker.aird`; empty model with default packages only. SA, LA and PA were not browsed.
3. **Expected vs actual:**
   - The clone found the `.aird` file and opened the project. (An earlier clone, before the model was pushed, returned an error for a missing `.aird`, which matched the repo being empty at that time.)
   - `list_object_types` returned object types for OA, SA, LA and PA, including OA Entity, Activity, Capability, Entity Exchange, Process, Exchange Item and PA Physical Link and Physical Path.
   - `browse_model` returned the four default OA packages with UUIDs (see OBS-0005 in `log_book`), and an empty list for OA entities.
4. **Reproduction:** clone the repo at commit `304e8a6`, then call `list_object_types` and the `browse_model` calls above.
5. **Scope:** none observed; the read path worked on a 6.1 model.
6. **Workaround:** not needed.
7. **Check in Capella 6.1:** not applicable to read-only calls.
8. **Tool version or build:** not known (open item in DEC-0007).

**Not yet covered:** `apply_model_patch`, `verify_model`, `pull_model_changes`, `push_model_changes`, `render_diagram_view`, `generate_fabric`, and reading a model with content.
