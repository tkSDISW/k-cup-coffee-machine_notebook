## Compat finding 16: a generated context diagram for an operational entity shows only the entity when its links exist between activities

**Result:** the render worked and returned a page, but the generated view holds **one element**, the entity itself.

1. **Tool and calls:** `render_diagram_view(target=<Coffee Drinker>, aspect="context")` returned the error `Entity supports context_diagram, realization_view, not 'context'`; then `aspect="context_diagram"` rendered.
2. **Context:** Capella 6.1 model `K Cup Coffee Maker.aird`, model commit `65bcea5` (the pushed set of operational activities, exchange items and interactions). Target: Coffee Drinker (`689a685b-ebfd-4b53-bc72-e55c5727210d`), which has 13 allocated activities and many interactions at activity level, but **no entity-level communication means**.
3. **Expected vs actual:** expected a context showing the drinker and the entities it interacts with. Actual: `elements: 1`, layout `computed`, 4079 bytes. The generated context follows links between entities; the interactions here are between activities allocated to entities, so the entity-level view has nothing to draw.
4. **Observations**
   - The error for the wrong aspect name lists the valid names, which was helpful.
   - `aspects_available` for an entity: `context_diagram` and `realization_view`.
   - A view built around an **activity** (which has the interactions) may show more; not tried here.
5. **Suggestion to the tool maintainer:** for an operational entity with no communication means, derive the entity-level context from the interactions between its activities and the other entities' activities (an aggregate view), or say in the result why the view is empty.
6. **Reproduction:** render `context_diagram` for an entity whose activities have interactions but which has no communication means.
7. **Scope:** none observed; not specific to 6.1.
8. **Workaround:** draw the entity-level view in Capella (communication means cannot be created by patch), or render a view around an activity.
9. **Tool version or build:** not known (open item in DEC-0007).
