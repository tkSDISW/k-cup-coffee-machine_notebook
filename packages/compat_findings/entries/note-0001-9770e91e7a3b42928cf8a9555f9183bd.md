## Purpose of this package

Findings from using the `capella-fabric` tools on a **Capella 6.1** model (project `K Cup Coffee Maker`, repo `tkSDISW/k-cup-coffee-machine`, branch `master`). The tools originated on 6.1 and were updated for 7.0.1; the maintainer's test suite runs on 7.0.1, so confirmations on 6.1 are as useful as problems. Findings are collected here so they can be handed back to the tool maintainer separately from the modeling narrative in `log_book`. Background and rationale: DEC-0007 in `log_book`.

**One entry per finding, titled "Compat finding N: ..."** (N counts up from 1). Each records:
1. **Tool and call:** tool name and arguments used, with any patch text.
2. **Capella and model context:** Capella version, model commit before and after, phase and element UUIDs involved.
3. **Expected and actual result,** including any error text.
4. **Reproduction steps,** short enough to rerun.
5. **Scope:** appears specific to 6.1, to the tools, or to this model's content; or unknown.
6. **Workaround,** if any.
7. **Check in Capella 6.1:** whether the model opened and displayed correctly afterward (engineer confirms).
8. **Tool version or build,** if it can be determined.

**Conventions**
- Describe behavior and evidence neutrally, without blame or judgment about the tools or their authors.
- Log confirmations briefly ("tool X worked on 6.1 for operation Y at commit Z").
- Keep each finding self-contained, so it can be copied out on its own.
- Do not put modeling decisions here; those stay in `log_book`.
